# Дипломный проект — часть 3. UI-тестирование Stellar Burgers

## О проекте

Проект содержит автоматизированные UI-тесты веб-приложения **Stellar Burgers**.

**Тестируемое приложение:** https://stellarburgers.education-services.ru/

Тесты написаны на Python с использованием Selenium WebDriver и pytest. Для организации кода применяется паттерн Page Object Model (POM).

Тестирование выполняется в браузерах Google Chrome и Mozilla Firefox.

## Проверяемая функциональность

### Раздел «Конструктор»

1. Переход из раздела «Лента заказов» в «Конструктор».
2. Переход из «Конструктора» в «Ленту заказов».
3. Открытие модального окна с информацией об ингредиенте.
4. Закрытие модального окна ингредиента.
5. Увеличение счётчика ингредиента после добавления в конструктор.

### Раздел «Лента заказов»

6. Увеличение счётчика «Выполнено за всё время» после оформления заказа.
7. Увеличение счётчика «Выполнено за сегодня» после оформления заказа.
8. Отображение оформленного заказа в ленте заказов.

Всего реализовано **8 тестовых сценариев**, каждый из которых выполняется в Chrome и Firefox — **16 проверок**.

## Установка и запуск тестов

Для выполнения тестов необходимо установить Google Chrome и Mozilla Firefox.

### 1. Установка зависимостей

```bash
python -m pip install -r requirements.txt
```

### 2. Запуск всех тестов

```bash
python -m pytest tests -v
```

### 3. Запуск тестов с формированием результатов Allure

```bash
python -m pytest tests --alluredir=allure-results --clean-alluredir
```

### 4. Просмотр отчёта Allure

При установленном Allure CLI:

```bash
allure serve allure-results
```

## Особенности реализации

- Используется паттерн Page Object Model.
- Локаторы вынесены в отдельные классы.
- Тесты параметризованы для Chrome и Firefox.
- Тестовые пользователи создаются и удаляются через API.
- Для работы с элементами используются явные ожидания Selenium.
- Добавление ингредиентов реализовано с помощью drag-and-drop.
